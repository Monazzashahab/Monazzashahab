# Monazza Shahab, PhD

Pharmacologist and neuroscientist working on machine learning for biological data and on AI evaluation for the life sciences. Based in Columbus, OH.

## Projects

- **[Cochlear synaptosome proteomics](https://github.com/Monazzashahab/cochlear-synaptosome-composition-ml)** (Python): Nested machine learning and tissue-composition reanalysis of a TMT proteomics dataset. Sole-author [preprint](https://doi.org/10.21203/rs.3.rs-11340135/v1).
- **[Exercise transcriptomic meta-analysis](https://github.com/Monazzashahab/lpfc-transcriptomic-meta-analysis)** (R): Cross-platform meta-analysis of public GEO datasets. Senior and corresponding author on the [preprint](https://doi.org/10.64898/2026.10.27.762209).
- **SPIEO, Synaptic Plasticity Inference Engine from Omics** (Python): Independent project that predicts synaptic plasticity outcomes from omics data. In progress, code not yet public.
